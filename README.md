# Panzer Fight Stick 4

Design files for the **Panzer Fight Stick 4**, provided for **personal, non-commercial use only.**

## What's in This Repo

This repository contains DXF files (`.dxf`) for the Panzer Fight Stick 4. These parts are intended to be **manufactured from sheet metal by a sheet metal fabrication shop.**

> **Please read the License and Disclaimers below before using anything in this repository.**

## Manufacturing

The DXF files in this repository are cut-file designs meant to be sent to a sheet metal shop for fabrication (laser cutting, waterjet, punching, bending, etc.).

**Recommended material:** Cold Rolled Steel, 16 gauge (.060 in), finished with powder coating.

- You are responsible for selecting a shop and specifying material, thickness, finish, tolerances, and any bends or secondary operations.
- The files are provided as-is; no material specification, cut settings, or shop instructions are implied or included beyond the geometry itself.
- Always confirm the design, dimensions, and fit with your fabricator before ordering.
